# Bundled fonts

IosevkaTerm-Regular.woff2 is the unmodified regular webfont from Iosevka v34.8.1:
https://github.com/be5invis/Iosevka/releases/tag/v34.8.1
Archive: PkgWebFont-IosevkaTerm-34.8.1.zip, entry WOFF2/IosevkaTerm-Regular.woff2.

Its copyright and SIL Open Font License are in Iosevka-LICENSE.md.
It is the one bundled terminal font and the fixed default on every platform.
It includes terminal symbols such as U+23F5 ⏵ at the same advance width as
Latin letters. Chinese and other unsupported characters use system fallback.
Custom fonts remain optional and must be installed on the device; Iosevka
Term remains their fallback. No third-party font request is made.

Nunito Variable and Fredoka Variable are the existing bundled interface fonts.
