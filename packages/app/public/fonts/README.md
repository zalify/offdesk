# Bundled fonts

JetBrainsMono-Regular.woff2 is the unmodified regular webfont from JetBrains Mono v2.304:
https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/webfonts

Its copyright and SIL Open Font License are in JetBrainsMono-OFL.txt. It is served locally with the app; no third-party font request is needed. It covers terminal Latin text; CJK and missing glyphs continue to use system fallback fonts.

Nunito Variable and Fredoka Variable are the existing bundled interface fonts.
