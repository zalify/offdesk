# Terminal input

Local editor has been removed from current clients. Text now goes directly to the terminal; there is no input-mode selector or local draft submission.

Use the key bar’s Paste action, your keyboard’s clipboard, or Cmd/Ctrl+V. Pasting uses the terminal’s bracketed-paste mode when supported and does not append Enter or open the keyboard. Press Enter when ready to submit. On shells without bracketed-paste support, pasted newlines follow that shell’s normal behavior.

Photo and file uploads remain available through the attachment button. See [File attachments](file-attachments.md).

Existing local drafts are no longer loaded or sent automatically. Their on-device storage is left untouched. The Hub and Node retain the composer protocol for compatibility with older installed clients.
