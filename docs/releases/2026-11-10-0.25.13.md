# 0.25.13 — A quieter sessions sidebar

Release scope: everything, in the one release `v0.25.13`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.25.12. The changes are interface only (OFF-124); the
release ships them in the interface built into the Hub and the apps.

## Changes

- **The sessions sidebar is full height and one line per terminal** (#627),
  after kero.sh and herdr.dev. Wireframes: `docs/plans/2026-11-10-sidebar-restyle.md`.
  - On windows 1024px and wider the sidebar is a 248px column at the left
    edge. While it is shown there is no tab bar: tabs are its groups (name,
    pane count, `n waiting`), and the pane headers line up with its top row.
    Hiding it brings the tab bar back. Narrower windows keep it as a drawer.
  - Rows are one 30px line: title, then `waiting`, `now`, the age or
    `offline`, and one state mark. Close appears on hover; move to another
    tab and close are on right-click.
  - Group headers fold on click, have `+` (new terminal in this tab) and `⋯`
    (new tab, rename, close) on hover, and drag to reorder; rows drag onto a
    group to move.
  - The machine switcher, its load and latency, and the files, agent
    browser, phone and settings icons moved into the sidebar; the status line
    no longer repeats the latency while it is shown.
  - The default order is by tab; the clock button switches to latest output
    first.
  - Terminals an agent opened carry a robot icon (and an `agent` badge in
    pane headers) instead of `⌁ opened by …`; which agent is in the tooltip.
- **The phone's sessions sheet uses the same rows** (#628). Rows are 44px with
  no close button: hold one to close it, open a new terminal in its tab, or
  move it to another tab. A tab's header opens that tab's actions (new
  terminal here, new tab, rename, move up or down, close), which replaces the
  separate tabs sheet. The machine sits in the sheet's header and `new
  terminal` at the bottom, within thumb reach.

## Upgrading

- Nothing to migrate. The sidebar remembers whether it was hidden, as before.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.13` on the merge
  commit. The Release workflow checks the tag against both versions, builds
  every component into the draft, and publishes it once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded, not skipped.
- After publishing:
  - `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.25.13, and a desktop app on 0.25.12
    offers the update.
  - `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.13.
  - A desktop window at 1280px shows the sidebar without a tab bar; the phone
    sheet's rows open their actions on a long press.
  - Offer the iOS build to testers with `TestFlight Release Distribution`,
    `release_tag` `v0.25.13`.
  - Publish the Web UI to `stable` so installed apps on 0.25.12 get the new
    interface too.
