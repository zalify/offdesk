# 0.28.0: files for an agent, saved on its machine

Release scope: everything ships in the one release `v0.28.0`, upgrading from
0.27.1:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux;
- the Android app;
- iOS, through TestFlight.

Only the Hub changed. The node, the CLI and the apps are rebuilt at the new
version with no other changes.

## Changes

- **Files for a run's agent, saved on its machine** (#655, OFF-143).
  - New bridge commands `upload_begin`, `upload_chunk` and `upload_end`, and
    `POST /api/agent-runs/{id}/files/begin|chunk|end` for tokens with
    `runs:message`, save a file of up to 100 MB in
    `~/.offdesk/attachments/<run>` on the run's machine, through the node's
    existing file transfer (`fs-ops-v1`). The answer is the file's path, for
    the message to name; a name already there is kept and the new file gets
    another.
  - Chunks go one at a time and in order. A failed chunk ends the upload. A
    node without `fs-ops-v1` answers 503, an ended run 409, a file too large
    413.
  - Each upload counts toward the bridge's `max_answers_per_hour`, and
    `upload_end` is audited. Chunk data is never logged.
  - offdesk.so uses it to attach pictures, recordings and files to a message
    for an agent; it hides attachments for Hubs older than 0.28.0.

## Upgrading

- Update the Hub on each machine (the desktop app updates its bundled one).
  Nothing else needs to change first.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.28.0` on the
  merge commit. The Release workflow checks the tag, builds every component
  into the draft, and publishes the release once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded rather than skipped.
- After publishing:
  - Check that `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.28.0.
  - With a Hub on 0.28.0 paired to offdesk.so, attach a file to a message for
    an agent and check it lands in `~/.offdesk/attachments/<run>`.
  - Offer the iOS build to testers with `TestFlight Release Distribution`
    (`release_tag` `v0.28.0`).
