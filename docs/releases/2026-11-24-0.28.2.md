# 0.28.2: Antigravity (`agy`) agent support

Release scope: everything ships in the one release `v0.28.2`, upgrading from
0.28.1:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux;
- the Android app;
- iOS, through TestFlight.

The protocol, Hub, node, CLI and shared types changed. The desktop and mobile
apps are rebuilt at the new version.

## Changes

- **Antigravity (`agy`) support across protocol, node and CLI** (#659).
  - Protocol & shared types: add `RunAgent::Antigravity` (`antigravity` / `agy`),
    permission mode flags (`--mode accept-edits|plan|auto`), and Antigravity
    `hooks.json` helpers.
  - Node detection & activity: recognize foreground `agy` / `agy.exe`, read
    Antigravity's live footer (`esc to cancel` vs `? for shortcuts`) so idle
    TUI repaints no longer mark terminals as `now`/working, probe `agy` on
    PATH, start runs with `-i` / `--conversation`, and revive Antigravity
    sessions after reboot via `~/.gemini/antigravity-cli/presence/<uuid>.lock`.
  - CLI hooks & start: handle `offdesk hook antigravity <event>` (printing `{}`
    on stdout), install/uninstall the `"offdesk"` entry in
    `~/.gemini/config/hooks.json` (`offdesk agents hooks install --agent antigravity`),
    and accept `--agent antigravity` (alias `agy`).

## Upgrading

- Update the Hub, node and CLI (`curl -fsSL https://offdesk.dev/install | sh` or
  the Hub container image).
- On machines running Antigravity CLI, run `offdesk agents hooks install --agent antigravity`
  so new `agy` sessions report their lifecycle state to Offdesk.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.28.2` on the
  merge commit. The Release workflow checks the tag, builds every component
  into the draft, and publishes the release once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded rather than skipped.
- After publishing:
  - Check that `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.28.2.
  - Verify idle `agy` terminals no longer show `now`/active spinner while idle,
    and working `agy` terminals do.
  - Offer the iOS build to testers with `TestFlight Release Distribution`
    (`release_tag` `v0.28.2`).
