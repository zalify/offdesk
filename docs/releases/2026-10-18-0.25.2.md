# 0.25.2 — Faster connection checks, steadier keyboard

Release scope: everything, in the one release `v0.25.2`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.25.1. The changes are in the apps; the Hub, node and CLI
only carry the version.

## Changes

- **Connection checks answer as each address does** (#582). In **Hub &
  connections**, every address shows its result the moment it answers, so a
  relay that answers in 40 ms no longer waits behind a LAN address that can't
  be reached on mobile data. A check now gives up on a LAN address after 1.5 s
  and a remote one after 3 s (it was 8 s, then discovery and the machine list
  one after the other); connecting for real still waits 8 s. The streaming is
  in the native shell, so it needs this build; an older UI against it, or this
  UI against an older shell, still gets the whole report at the end.
- **The terminal refits the frame after the keyboard moves** (#583). Opening
  the phone keyboard no longer leaves the old grid clipped under it, prompt
  included, and closing it no longer leaves the bottom half blank, both for the
  150 ms the refit used to wait. The same goes for a foldable opening or
  closing, and on a large touch layout (iPad) every pane refits when the iOS
  keyboard moves, not only the active one. Interface only: it also reaches
  0.25.1 apps through the `stable` Web UI channel.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.2` on the merge
  commit. The Release workflow checks the tag against both versions, builds
  every component into the draft, and publishes it once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded, not skipped.
- After publishing:
  - `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.25.2, and a desktop app on 0.25.1
    offers the update.
  - `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.2.
  - On a phone on mobile data with a saved LAN address, **Hub & connections**
    shows the relay's latency at once and the LAN address as unreachable within
    about 1.5 s.
  - Offer the iOS build to testers with `TestFlight Release Distribution`,
    `release_tag` `v0.25.2`.
- Publish the same Web UI to the `stable` channel.
