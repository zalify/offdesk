# 0.33.0: Built-in Rust Alacritty Terminal, Agent Drafts & Artifacts, Cross-Machine Agent Bus, Headless Bots & Encrypted Vault

Release scope: everything ships in the one release `v0.33.0`, upgrading from
0.32.0:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux (with auto-updater);
- the Android app;
- iOS, through TestFlight.

## Changes

- **Built-in Rust `alacritty_terminal 0.25` engine inside the Tauri app (Route A, zero `xterm.js`)**:
  - Added Tauri native terminal IPC commands (`native_term_open/feed/resize/scroll/snap_bottom/plain_lines/close`) powered by `alacritty_terminal 0.25` with 10,000-line Rust scrollback, Retina HiDPI canvas rendering, `deflate-raw-v1`, CJK IME, bracketed paste, and drag selection/copy.
  - Added a 1-click **Terminal engine** selector in Settings (`Native Rust (Alacritty)` vs `Legacy (xterm.js)`) with automatic graceful fallback on web browsers.
- **Agent Scratchpad Drafts & Claude-Artifact Previewer**:
  - Added Hub SQLite `/api/drafts` API, `offdesk draft write/list/read/archive/rm` CLI, and a Desktop/Mobile `DraftsDrawer` featuring `DraftArtifactPreview` (GFM tables, Mermaid diagrams, sandboxed SVG/HTML artifacts, wide-mode toggle, and 1-click Send to Terminal).
- **Cross-Machine Agent Bus (`offdesk msg`)**:
  - Added Hub SQLite `agent_messages` table & `/api/messages` API, `OFFDESK_TERMINAL_ID` injection in `pty-daemon`, and `offdesk msg send/post/inbox/tail/wait` CLI commands for structured agent-to-agent collaboration across machines.
- **Parallel `chat (beta)` Workspace: Headless Bots, `#Channel` Group Chat & Encrypted Vault**:
  - Added direct headless stream-JSON runner (`crates/machine/src/headless_agent.rs`) for `claude` and `codex` (<1s startup, multi-turn `--resume`, structured streaming deltas & tool calls). Bots run as independent orchestrators (not bound 1:1 to a terminal).
  - Added `#channel` multi-agent group chat routing (`/api/chat/channels/{channel}/send`) with `@mention` dispatch and `MAX_GROUP_CHAT_HOPS = 3` anti-loop protection.
  - Added ChaCha20-Poly1305 encrypted **Secrets, Accounts & API Keys Vault** (`/api/vault`) with masked list previews, explicit reveal/copy, automatic scoped `Env Var` injection into Bots, and output secret redaction.
- **Native GPU renderer performance & Retina fixes**:
  - 386× faster `TextBufferCache`, persistent GPU quad vertex buffer, O(1) dirty-gen frame cache, Retina 16K texture limit fix, and `compression_enabled` handshake fix.
