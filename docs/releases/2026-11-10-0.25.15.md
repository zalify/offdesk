# 0.25.15: "Recent" means someone or the agent did something

Release scope: everything ships in the one release `v0.25.15`, upgrading from
0.25.14:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux;
- the Android app;
- iOS, through TestFlight.

The only change is in the node.

## Changes

- **Clicking a Claude Code session no longer lifts it in "recent" a few
  seconds later** (#633). 0.25.14 ignored output in the 3 seconds after a
  viewer resized or focused a terminal. Claude Code also prints without
  working, and later than that:
  - When it gains focus with an image on the clipboard, it shows "Image in
    clipboard" and hides it again about 9 seconds later.
  - It writes a recap while in the background.
  - It changes its status line.

  The node now counts a terminal as active in these cases:
  - **Someone types into it.** Keys, a paste, the composer, or an answer sent
    to its agent all count. The focus, mouse and reply sequences the viewing
    terminal sends by itself don't.
  - **Claude Code or Codex shows a turn in progress.** For these two, output
    counts only during a turn: Claude's spinner line ("✻ Sprouting… (6s)") or
    Codex's "Working (… esc to interrupt)".
  - **Any other program has output,** as before.

## Upgrading

- The fix needs the new node on each machine. With an older node the order
  behaves as before.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.15` on the
  merge commit. The Release workflow:
  - checks the tag against both version numbers;
  - builds every component into the draft;
  - publishes the release once every asset and `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded rather than skipped.
- After publishing:
  - Check that `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.25.15, and that a desktop app on 0.25.14
    offers the update.
  - Check that `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.15.
  - In "recent" order, click an idle Claude Code session while an image is on
    the clipboard: it keeps its place. Type into it: it moves to the top.
  - Offer the iOS build to testers with `TestFlight Release Distribution`
    (`release_tag` `v0.25.15`), and publish the Web UI to `stable`.
