# iOS 0.9.1 — themes, and interface updates without TestFlight

Release scope: iOS through TestFlight (`ios-v0.9.1`). Desktop, Android and
the Hub stay on 0.9.0 / 0.22.0: their apps already took this interface as a
Web UI update.

## Changes

- **Themes** (#535): Graphite, a softer dark, is the default; Midnight keeps
  the 0.9.0 look; Slate, Ember, Paper and the eye-care Sepia and Sage join
  them. The terminal follows the theme. Choose in Settings › Appearance, or
  from [m] › appearance, which tries a theme, the terminal font and its size
  on the live terminal (cancel puts them back).
- **Interface updates over the air** (#536): this build carries the Web UI
  release key, so later interface changes reach the iPhone and iPad app like
  the other apps, without a new TestFlight build. The app itself still
  updates through TestFlight.

## Validation and publication

- Run CI on the release preparation, then merge and tag `ios-v0.9.1` on the
  merge commit.
- Verify the build reached TestFlight. Install it and check Settings › About
  shows an interface version and the shell's Web UI channel is `stable`.
- Publish the iOS release without moving GitHub's global Latest off the Hub
  release.
