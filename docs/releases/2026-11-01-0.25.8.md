# 0.25.8 — Typing right after returning from the background

Release scope: everything, in the one release `v0.25.8`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.25.7. The fix is interface-only and also reaches 0.25.7
apps through the `stable` Web UI channel.

## Changes

- **Keys typed right after returning from the background reach the terminal**
  (#609). Coming back to the app (or showing the browser tab again) replaces
  the terminal connection, because a phone's connection can die in the
  background without saying so. The new one waited a second, and the first
  keys typed meanwhile were lost. Now it reconnects at once, and input typed
  while the terminal reconnects waits and is sent when it is back. Input
  older than 10 seconds is not replayed, and neither are mouse and scroll
  reports.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.8` on the merge
  commit. The Release workflow checks the tag against both versions, builds
  every component into the draft, and publishes it once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded, not skipped.
- After publishing:
  - `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.25.8, and a desktop app on 0.25.7
    offers the update.
  - `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.8.
  - On a phone, switch to another app and back, then type at once: every key
    arrives.
  - Offer the iOS build to testers with `TestFlight Release Distribution`,
    `release_tag` `v0.25.8`.
- Publish the same Web UI to the `stable` channel.
