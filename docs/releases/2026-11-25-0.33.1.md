# v0.33.1

## Highlights
- **Native Rust Alacritty Terminal Unlocked (Tauri v2 ACL)**: Granted desktop and mobile Tauri capabilities for all 7 `native_term_*` IPC commands (`native_term_open/feed/resize/scroll/snap_bottom/plain_lines/close`) and exposed live active engine status in Settings.
- **First-Principles Native Terminal Sizing & Smooth UX**:
  - PTY-locked local grid dimensions + strict FIFO IPC serialization + webfont-ready offscreen cell measurement (eliminates split-pane wrapping and cursor drift).
  - macOS-style auto-fading draggable scrollbar (`history_size` exposed on `NativeTermFrame`), 120Hz trackpad momentum scrolling, drag-to-copy with `Copied` feedback, double-click word / triple-click line selection, right-click context menu, `⌘+Click` URL & in-app file preview, `⌘F` 10,000-line scrollback search, and chunked paste/drop file upload.
- **Workspace & Drafts UX**:
  - Prominent `Terminals | Bots & Chat` sidebar switcher, `Group by project` worktree grouping, auto-hidden Background Shelf (`minimize to shelf` + 1-click restore), and 1-click Stage Layout Presets (`Focus` / `Split` / `2×2`).
  - Draggable left-edge resize handle on the Drafts drawer (persisted in `localStorage`).
- **Node & CLI**:
  - Full-machine-reboot auto-resume for `native` `pty-daemon` Claude & Antigravity sessions (`send_keys_line` + empty-`tmux` Claude session matching).
  - `offdesk vault list / set / reveal / rm` CLI subcommands for the encrypted secrets vault.
