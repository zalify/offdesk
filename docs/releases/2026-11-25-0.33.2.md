# v0.33.2

## Highlights
- **Ghostty & Alacritty Terminal Parity (Rust + Canvas)**:
  - ANSI SGR 2 (`DIM` / `NamedColor::Dim*`) muted gray rendering for Claude Code ghost autocomplete suggestions.
  - Underline (all 5 styles), strikeout, OSC 8 implicit hyperlinks + `⌘`-hover underline/pointer highlight, and OSC 52 remote clipboard auto-copy.
  - Dynamic `DECSCUSR` cursor shape (`block` / `beam` / `underline` / `hollow`) + unfocused hollow outline box + `DECCKM` (`app_cursor`) arrow keys.
  - Ghostty-style pixel-exact geometric Canvas rendering for Box Drawing & Block Elements (`U+2500..U+259F`).
  - Full macOS terminal keyboard (`Shift+Enter` newline, `Option+←/→`, `Option+Backspace`, `⌘+Backspace`, `⌘+←/→`, `F1–F12`) and `Option+Drag` rectangular block selection.
- **Zero-Flicker & Instant Tab Switching**:
  - DEC Mode 2026 Synchronized Output (`ESC[?2026h`…`ESC[?2026l`) atomic frame buffering eliminates `agy` / Ink TUI redraw flicker.
  - 32-pane Native Rust keep-alive pool (`< 1ms` tab switching), eager module/IPC preload, 0ms cached-frame paint, and zero-rAF first snapshot.
  - Chinese IME candidate bar anchored directly at the live terminal cursor, plus restored full workspace right-click `split` menu.
- **Scrollback & Drafts**:
  - `pty-daemon` replays up to 1,500 real scrollback lines with full SGR colors on attach; hides mismatched local scrollbar when remote owns scroll.
  - Drafts renders remote `file://<machine>/...` images inline (with transparent PNG checkerboard + full-screen lightbox zoom) and opens `file://` links in-app.
