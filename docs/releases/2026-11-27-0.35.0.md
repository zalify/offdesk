# v0.35.0

A Hub, node and CLI release. Spaces group terminals and drafts across every device; Antigravity started from Offdesk now asks before it acts, and the Hub tells Offdesk Cloud which agents each computer has; the native terminal's selection and scrolling get a round of fixes.

## What changed

### Spaces

- **Top-level Spaces** (#731): group terminals and drafts into Spaces, across the Hub, the desktop app, phones and foldables, and the CLI/TUI. A Space has a name, a color and a default folder for new terminals; Waiting badges show agents that need you in other Spaces. `/api/spaces` creates, edits and deletes them; deleting one moves its groups back to Default.
- **Default instead of All** (#732): the first tab is the Default Space and lists only groups that aren't in another Space, so moving a group into a Space takes it out of Default.

### Agents

- **Antigravity asks in ask mode** (#733): agy starts in its Auto mode when no mode is given, so a run started from Offdesk in ask mode ran commands and edits without asking. Ask mode now starts agy in its Default mode (`--settings '{"agentMode":""}'`).
- **Bridges see each machine's agents** (#733): the bridge snapshot and a `machine.online` event carry the coding agents a machine found installed (`claude`, `codex`, `antigravity`), so Offdesk Cloud offers only those (`docs/agent-bridge-protocol.md`).
- **`offdesk agents skill install|status|uninstall`** (#727): installs an `offdesk` skill that teaches Claude Code, Codex and Antigravity when to use `offdesk draft`, `db`, `browser`, `fetch`, `run`, `msg` and `vault` inside an Offdesk terminal.

### Terminal

- Content-anchored selection, and copying while dragging past the edge scrolls (#729).
- Left-drag selects text again in daemon terminals; a plain click opens file paths and URLs, including wrapped ones (#725).
- `pty-daemon` replays the alt screen on attach, so TUIs no longer leak status bars into scrollback, and the wheel always scrolls the remote program (#726).

### Phone and tablet

- Switching terminals in compact mode no longer leaves the loading bar stuck on an idle pane (#728).
- The unfolded foldable's left sidebar stays visible when the keyboard opens (#730).

## Updating

- Antigravity's ask mode needs the node at this version (it builds the command). Update the node on every machine that runs agy.
- The installed-agents list needs the Hub at this version, and the node since 0.33 (which reports what it found). Offdesk Cloud offers Antigravity only on machines whose Hub reports it.
- Spaces need the Hub and the app (the Web UI bundle); `offdesk tui` shows them with the CLI at this version.
- `offdesk agents skill` needs only the CLI.

## Check after publishing

- Start Antigravity from Offdesk in ask mode and ask it to run a command: it asks first. `ps` shows `agy --settings {"agentMode":""}`.
- In Offdesk Cloud, Agents › a computer with agy installed offers Antigravity in the hand-off sheet; a computer without it doesn't.
- Create a Space, move a group into it: the group leaves Default and shows only in that Space, on desktop and phone.
- `offdesk agents skill status` reports the skill; `install` writes `~/.agents/skills/offdesk/SKILL.md`.
