# 0.25.14 — Panes that fit, and "recent" that means output

Release scope: everything, in the one release `v0.25.14`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.25.13. The refit fixes are interface only; the activity
fix is in the node.

## Changes

- **Desktop panes refit when something resizes them** (#630). On desktop a
  terminal is fitted on explicit actions only, so a pane the layout resized
  kept its old size and left a margin (or was clipped).
  - Clicking a row in the sessions sidebar or drawer now focuses it the way a
    pane or tab click does: a row in another tab refits that tab's panes.
  - Showing or hiding the sidebar, and resizing the window, refit the visible
    panes on the device in control, without moving focus and only when the
    size changes. Opening a terminal still keeps the size it has.
  - Hiding the sidebar no longer switches to the first tab: the tab bar
    appeared under the still cursor and its hover-to-select fired. A tab is
    now selected by hover only once the pointer moves.
- **Looking at a terminal doesn't make it "recent"** (#631). The sidebar's
  latest-output order uses tmux's activity time, which moved whenever you
  opened a terminal: attaching, resizing and focusing it make Claude Code,
  Codex and other full-screen programs repaint. The node now ignores output
  within 3 seconds of a viewer resizing or focusing a terminal. Typing, the
  program's own output and a new terminal's first output still count.

## Upgrading

- The refit fixes reach installed apps through the interface (built into the
  Hub for browsers, bundled in the apps, and the Web UI `stable` channel).
- The activity fix needs the new node on each machine. With an older node the
  order behaves as before.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.14` on the merge
  commit. The Release workflow checks the tag against both versions, builds
  every component into the draft, and publishes it once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded, not skipped.
- After publishing:
  - `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.25.14, and a desktop app on 0.25.13
    offers the update.
  - `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.14.
  - Show and hide the sidebar on a desktop window: the terminal fills the pane
    each time and the tab stays. Click an idle session in "recent" order: it
    keeps its place.
  - Offer the iOS build to testers with `TestFlight Release Distribution`,
    `release_tag` `v0.25.14`, and publish the Web UI to `stable`.
