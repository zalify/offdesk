# Offdesk 0.35.1 — 2026-11-27

## Highlights
- **Reconnect reliability overhaul (#735)**:
  - Raised `offdesk_secure` logical socket cap from `32` to `128` on both client and Hub so multi-group desktop keep-alive never collides with the tunnel limit during reconnect bursts.
  - Made `Response::Error` and `Response::Closed` control-priority and switched Hub error delivery from lossy `try_send` to reliable `send().await`, preventing permanent `CONNECTING` hangs and slot leaks under backpressure.
  - Added wall-clock vs monotonic sleep detection to `offdesk_secure::client` heartbeat and tightened idle timeout to 25s so zombie tunnels after OS sleep tear down immediately.
  - Added a 10s `CONNECTING` handshake timeout on `SecureSocket`, fixed `TerminalView.native.tsx` wake/inflate/readiness handling, added a 1500ms desktop `groupHoldRef` safety timeout, and fixed the Hub `handle_machine_ws` disconnect cleanup race.
- **Space switcher UX (#735)**:
  - Desktop and mobile/foldable Space bars now wrap cleanly onto multiple rows with an accent-tinted active pill so every Space and `+` remain 1-click accessible.
- **CJK path click fix**:
  - Excluded Chinese/fullwidth punctuation (`：`, `，`, `。`, `（`, `）`, `【`, `】`, etc.) from native terminal path tokenization so clicking paths after CJK colons opens the exact target file.
- **UI & terminal smoothness overhaul**:
  - **Desktop native terminal & daemon**: Collapsed double-rAF feed/paint into a single-rAF pipeline, replaced global Rust terminal lock with per-terminal `Arc<Mutex<_>>` and zero-alloc ANSI color span merging, eliminated per-paint `getBoundingClientRect` / font-measure / textarea layout thrashing, stopped 80ms React re-renders during streaming output, removed resize dim/blur flash, serialized scroll IPCs, improved DEC 2026 sync-output framing & IME commit stability, and added burst output coalescing + overflow resync in `pty-daemon`.
  - **React root, sidebar & workspace**: Isolated `rttMs` and `machineStats` into a `useSyncExternalStore` mini-store (`liveMetricsStore`) so 2–5s telemetry/ping ticks no longer re-render the full app tree; guarded `CommandPalette` row recomputation when closed; restored `React.memo` across `SessionsSidebar`, multi-machine `TerminalWorkspace`, `WorkspacePaneTree`, `WorkspacePaneLeaf`, and `PaneHeader`; fixed per-render `onActiveRef` thrashing; equality-guarded `useVisualViewport` and prevented Space-pill font-weight wrap jitter.
  - **xterm.js & mobile/foldable**: Stopped no-op fits from clearing the WebGL texture atlas or running triple-rAF redraws; prevented hidden keep-alive panes from resize-thrashing; added adaptive debounce on rapid keyboard animations; isolated the 15s clock tick in `MobileWorkbench`; eliminated `cachedSnapshot` blank flash and `ExtendedKeyBar` observer loops.
- **Eliminated transient `take control` flash on reconnect**:
  - Extended Hub device disconnect grace period from 10s to 45s, restored stashed `released_leases` on `GET /api/bootstrap?device_id=...` before building the initial snapshot, and preserved prior `in control` UI state during transient reconnects unless another device explicitly takes control.
