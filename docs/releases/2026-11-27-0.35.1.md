# Offdesk 0.35.1 — 2026-11-27

## Highlights
- **Reconnect reliability overhaul (#735)**:
  - Raised `offdesk_secure` logical socket cap from `32` to `128` on both client and Hub so multi-group desktop keep-alive never collides with the tunnel limit during reconnect bursts.
  - Made `Response::Error` and `Response::Closed` control-priority and switched Hub error delivery from lossy `try_send` to reliable `send().await`, preventing permanent `CONNECTING` hangs and slot leaks under backpressure.
  - Added wall-clock vs monotonic sleep detection to `offdesk_secure::client` heartbeat and tightened idle timeout to 25s so zombie tunnels after OS sleep tear down immediately.
  - Added a 10s `CONNECTING` handshake timeout on `SecureSocket`, fixed `TerminalView.native.tsx` wake/inflate/readiness handling, added a 1500ms desktop `groupHoldRef` safety timeout, and fixed the Hub `handle_machine_ws` disconnect cleanup race.
- **Space switcher UX (#735)**:
  - Desktop and mobile/foldable Space bars now wrap cleanly onto multiple rows with an accent-tinted active pill so every Space and `+` remain 1-click accessible.
- **CJK path click fix**:
  - Excluded Chinese/fullwidth punctuation (`：`, `，`, `。`, `（`, `）`, `【`, `】`, etc.) from native terminal path tokenization so clicking paths after CJK colons opens the exact target file.
