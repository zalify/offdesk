# 0.28.3: Faster external access, tab switching, and terminal scrolling

Release scope: everything ships in the one release `v0.28.3`, upgrading from
0.28.2:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux;
- the Android app;
- iOS, through TestFlight.

The Hub, node, encrypted client, and web UI all changed.

## Changes

- **External access latency, tab switching, and scrolling optimizations** (#661).
  - **Hub HTTP compression**: added `tower-http` `CompressionLayer` (gzip,
    brotli, zstd) so static JS/CSS bundles and JSON API responses are compressed
    automatically.
  - **TCP_NODELAY on encrypted & node WebSockets**: enabled `disable_nagle` in
    `offdesk-secure`'s `Client::connect` and `offdesk-machine`'s hub connection
    to eliminate Nagle + Delayed ACK stalls on keystrokes over high-RTT links.
  - **Non-blocking node hub loop**: moved `FsListDir` and
    `CheckForegroundProcess` off the main receive loop onto `spawn_blocking` so
    slow disk/tmux operations never stall terminal input forwarding.
  - **Expanded desktop tab keep-alive LRU**: kept up to 4 recently active
    workspace groups mounted within the existing 8-pane WebGL budget so
    switching between up to 4 tabs is instant with no WebSocket/tmux rebuild.
  - **Smoother terminal scrolling**: coalesced pure SGR wheel bursts per
    animation frame (`requestAnimationFrame`) while keeping keystrokes on
    `queueMicrotask`, dropped excess wheel-only bursts when `ws.bufferedAmount`
    backs up over slow links, and switched touch scroll to live cell metrics
    with a cached `.xterm-viewport`.

## Upgrading

- Update the Hub, node and CLI (`curl -fsSL https://offdesk.dev/install | sh` or
  the Hub container image), and update desktop/mobile apps to pick up the
  `TCP_NODELAY`, LRU keep-alive, and scroll improvements.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.28.3` on the
  merge commit. The Release workflow checks the tag, builds every component
  into the draft, and publishes the release once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded rather than skipped.
- After publishing:
  - Check that `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.28.3.
  - Offer the iOS build to testers with `TestFlight Release Distribution`
    (`release_tag` `v0.28.3`).
