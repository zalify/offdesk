# 0.31.0: Agent Console UI polish and parallel native Rust GPU client

Release scope: everything ships in the one release `v0.31.0`, upgrading from
0.30.1:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux (plus parallel experimental
  `offdesk-native` binary in `crates/native-client`);
- the Android app;
- iOS, through TestFlight.

## Changes

- **Desktop Agent Console UI & interaction polish**:
  - **Clean CLI titles & shorter pane paths**: strips noisy CLI flags from
    raw process titles (e.g. `agy --dangerously-sk ~/p/webmux` → `agy · webmux`)
    while preserving explicit conversation titles, and shortens home paths to
    `~/...` in pane headers.
  - **Sidebar Agent Console upgrades**: adds a compact `All / Waiting / Working`
    status filter bar with live counts, background completion unread dots
    (`working → quiet/waiting` while inactive, cleared on selection), subtle
    breathing pulse on `waiting` indicators, and subdued empty group headers.
  - **Pane header hover quick actions**: hovering a desktop pane header reveals
    maximize/restore, split-right, and close buttons.
  - **Calmer status line + `⌘K` trigger**: removes the bright lime background
    from the default `in control` pill (reserving high-contrast highlight for
    `take control` when watching) and adds a `⌘K` quick-switcher trigger.
  - **Smart overflow tab naming**: derives overflow tab labels from the
    terminal's directory name (e.g. `webmux`, `webmux 2`) instead of `tab N`.
- **Parallel native Rust GPU desktop client (`crates/native-client`)**:
  - Added an experimental pure-Rust desktop client (`offdesk-native`) built on
    `winit`, `wgpu`, `glyphon`, and `alacritty_terminal` running alongside the
    existing Tauri app, with live Hub REST + `deflate-raw-v1` WebSocket
    streaming, 10,000-line local GPU scrollback, CJK IME/clipboard support,
    and `⌘K` / `⌘J` / `⌘⇧A` / `⌘T` shortcuts.
