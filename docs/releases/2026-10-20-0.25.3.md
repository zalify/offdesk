# 0.25.3 — Text size that sticks, steadier tab switching

Release scope: everything, in the one release `v0.25.3`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.25.2. The app changes are interface-only and also reach
0.25.2 apps through the `stable` Web UI channel; the Hub and CLI carry the
renaming below.

## Changes

- **Switching machine opens its first tab** (#591). After switching machine
  while a terminal on the old one was zoomed, the workspace showed an empty
  "new pane" tab even when the new machine had tabs. It now opens the new
  machine's first tab (OFF-45).
- **The Interface text size scales the whole interface** (#590). The setting
  used to reach almost none of the UI's text, which was fixed in px. Every UI
  font size now follows it, form fields included; at the default nothing moves.
- **Form fields follow the text size on iOS** (#589). Fields are no longer
  forced to 16px. Instead the viewport is capped at scale 1, so WebKit still
  doesn't zoom into a focused field. In the iOS app this also stops pinch-zoom
  of the interface; the text size setting replaces it.
- **Tab switching on desktop keeps the old group on screen until the new one
  has drawn** (#585), instead of flashing blank while panes reattach.
- **Naming** (#586): the hosted product is Offdesk (offdesk.so), previously
  Offdesk Cloud, in the app, Hub messages and docs. `offdesk mcp` now registers
  as `offdesk-dev`; an existing `offdesk` registration keeps working.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.3` on the merge
  commit. The Release workflow checks the tag against both versions, builds
  every component into the draft, and publishes it once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded, not skipped.
- After publishing:
  - `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.25.3, and a desktop app on 0.25.2
    offers the update.
  - `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.3.
  - Zoom into a terminal on one machine, switch to another with tabs: its
    first tab shows, not "new pane".
  - Set Interface text size to 20: the Settings title and form fields grow.
  - Offer the iOS build to testers with `TestFlight Release Distribution`,
    `release_tag` `v0.25.3`.
- Publish the same Web UI to the `stable` channel.
