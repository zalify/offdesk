# Desktop, Android and iOS 0.7.10 — Browser toolbar

Release scope: desktop macOS, Windows, and Linux (`desktop-v0.7.10`), Android
(`app-v0.7.10`), and iOS through TestFlight (`ios-v0.7.10`).

## Changes

- The agent browser has a toolbar: back, forward, reload (stop while a page
  loads) and an address you can edit, while you are in control, with a
  loading bar and Chrome's shortcuts (⌘[ ⌘] ⌘R ⌘L on a Mac). On the phone,
  back, forward and reload are in the bar under the page.
- A page's alert, confirm, prompt or "Leave site?" dialog is shown over the
  page and answered by whoever is in control. Agents answer with
  `offdesk browser dialog <browser> accept|dismiss` (MCP: `browser_dialog`);
  an action that opens a dialog returns at once instead of hanging.
- A window a page opens, such as a "Sign in with Google" popup, becomes its
  own tab, comes to the front and is yours if you were in control; when it
  closes itself you are back on the page that opened it.
- The agent browser no longer calls itself HeadlessChrome, so sites behind
  Cloudflare treat it like a normal Chrome instead of challenging every page.
- iOS also gets 0.7.9's file preview: the `ios-v0.7.9` build failed while
  installing the Tauri CLI, which is fixed here.

The toolbar, dialogs and popups need this release's node and Hub (the Hub
bundled with the desktop app); `offdesk browser dialog` needs the CLI from
this commit.

- Run CI on the release preparation, then merge and tag `desktop-v0.7.10`,
  `app-v0.7.10`, and `ios-v0.7.10` on the merge commit.
- Verify the desktop draft as for 0.7.8, then publish without moving

  manifest.
- Verify the Android release APK is signed and starts, and that the iOS
  build reached TestFlight.
