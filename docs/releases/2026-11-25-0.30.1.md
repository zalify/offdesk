# 0.30.1: Native pty-daemon local DSR/DA replies and initial desktop pane fit

Release scope: everything ships in the one release `v0.30.1`, upgrading from
0.30.0:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux;
- the Android app;
- iOS, through TestFlight.

## Changes

- **Native `pty-daemon` local terminal query interception**:
  - `offdesk-node pty-daemon` now intercepts and replies locally to standard
    terminal queries (`ESC[6n` / `ESC[5n` DSR, `ESC[c` / `ESC[0c` DA1,
    `ESC[>c` / `ESC[>0c` DA2) in sub-millisecond time using its authoritative
    `vt100` cursor position and strips the queries before forwarding to
    attached clients. Fixes `fish` and TUI startup input stalls on fresh split
    panes and eliminates WAN round-trips during shell startup.
- **Native `pty-daemon` SGR mouse-wheel scrollback**:
  - Added 10,000-line in-memory scrollback handling in `pty-daemon` for apps
    that do not enable mouse tracking themselves (such as `agy`, `fish`,
    `bash`), while passing mouse events straight through to mouse-aware TUIs
    such as Claude Code and `vim`.
- **Fit newly created desktop terminals to actual pane dimensions**:
  - Creating a new terminal from the desktop header now triggers
    `fitVisiblePanes()` once mounted, correcting the rough initial full-window
    dimension estimate (which previously could overshoot pane height and clip
    bottom-pinned inputs such as Claude Code's prompt bar).
