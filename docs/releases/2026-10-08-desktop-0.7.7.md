# Desktop 0.7.7 — fewer, sharper features

Release scope: desktop macOS, Windows, and Linux. Tag: `desktop-v0.7.7`.
The desktop app bundles its interface and, on macOS and Linux, the Hub and
node sidecars, so these changes reach a machine once its desktop app updates.

## Changes

- Removed the agent relay ("Continue in Codex/Claude"): the agent chip, the
  usage-limit card and the brief sheet. To get a second opinion, ask Claude
  Code to run a Codex review in the same session.
- Removed to-dos: the to-do panel and its top-bar and phone-menu entries,
  handing a to-do to Claude or Codex, and `offdesk todo`. Use GitHub issues
  instead (`gh issue create`).
- The node no longer scans each terminal's processes and Claude session files
  every few seconds; only the relay and to-dos used that.
- The desktop tab strip no longer shows scrollbars when its tabs overflow. A
  vertical mouse wheel scrolls the tabs sideways.

Existing `hub.db` files keep their to-do table and relay columns, unused.
`offdesk mcp` and `offdesk browser` work as before.

## Validation and publication

- Run CI on the release preparation, then merge and build the release commit
  with the existing Desktop Build workflow for all three platforms.
- Verify the draft assets, macOS signing/notarization and DMG layout, and the
  updater manifest's version, platform URLs, and signatures before publishing.
- Keep GitHub's global Latest on the standalone Hub release and verify the
  floating `desktop-latest` manifest after publishing Desktop 0.7.7.
