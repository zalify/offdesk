# 0.25.0 — Offdesk Dev: a new name and mark, Offdesk Relay, updates from offdesk.dev

Release scope: everything, in the one release `v0.25.0`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.24.0.

## Changes

- **Offdesk Dev** (#571). The app is called Offdesk Dev, and its mark takes
  Offdesk's composition: the same hand-drawn desk and speed lines, light on
  dark, with a terminal window flying off it. Every icon, the favicons, the
  share card and the DMG background are redrawn. On macOS an updated app keeps
  its folder name, `Offdesk DEV.app`; at its first launch it renames itself to
  `Offdesk Dev.app` and points the Hub, node and Cloud connector services at
  the new path. Release files are named `Offdesk.Dev_…` from now on.
- **Offdesk Relay for managed connections** (#562). `offdesk-hub cloud install`
  moves the managed connection from a Cloudflare tunnel to Offdesk Relay: the
  Hub measures the relay regions directly, picks a home and a backup, and
  keeps a connection to each; nothing is downloaded, and the relay only passes
  Noise records. The address becomes `https://<slug>.relay.offdesk.cloud`, with
  the home and backup regions' own addresses advertised after it.
  `cloud regions` shows the measurements, `install --home/--backup` chooses.
  Hubs already on a tunnel keep cloudflared until `install` runs again (the
  desktop app's **Enable remote connection** does that); phones pair again on
  the new address.
- **Updates from offdesk.dev** (#573). The desktop updater, Web UI updates,
  the Android updater, the iPhone notice, the Hub's version check and the
  installer ask offdesk.dev first and GitHub second, and download from
  offdesk.dev, which serves a copy of every release from R2. GitHub is
  unreliable from mainland China without a proxy. Signatures are checked as
  before, so a mirror can't substitute a file.
- **Routes** (#564, #565, #567, #569, #570). Checking a Hub's connections keeps
  a working address the Hub doesn't list (the relay address on an older Hub);
  a re-paired Hub shows its new address rather than the old one; each route
  shows its latency.
- **Phone** (#556–#561, #568). Screen recordings from the photo picker; a tab
  bar with a fixed new-tab button; switching tabs without the blank flash, the
  held screen fading out when a switch lands; the phone title as a sessions
  picker, Enter on the accent key; settings on foldables.
- CI: E2E in four shards (#563), the Android check only for Android changes on
  pull requests (#572), a steadier emulator (#566).

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.0` on the merge
  commit. The Release workflow checks that the tag matches both versions,
  builds every component into the draft, and publishes it once every asset
  and `latest.json` are in place.
- The mirror steps need `CLOUDFLARE_API_TOKEN` with Workers R2 Storage: Edit
  (added 2026-10-18). Check that `updater-channel` and `mirror` uploaded, not
  skipped.
- After publishing:
  - `https://offdesk.dev/updates/desktop/latest.json` names 0.25.0 with links
    under `https://offdesk.dev/download/v0.25.0/`; GitHub's
    `desktop-latest/latest.json` names it too. A desktop app on 0.24.0 offers
    the update (it still checks GitHub; from 0.25.0 on it checks offdesk.dev).
  - On macOS, the updated app relaunches as `/Applications/Offdesk Dev.app`,
    and `~/Library/LaunchAgents/dev.offdesk.*.plist` name that path.
  - An Android app on 0.24.0 offers 0.25.0, and `https://offdesk.dev/apk`
    downloads it from offdesk.dev.
  - `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.0, and
    `offdesk version` reports it.
  - On a Hub with a managed connection, **Enable remote connection** (or
    `offdesk-hub cloud install`) moves it to the relay: `cloud status` shows
    `"transport":"relay"` and the relay URL, and `cloud check` passes. A phone
    paired on that address connects over mobile data.
  - The iOS build reached TestFlight; offer it to testers with `TestFlight
    Release Distribution`, `release_tag` `v0.25.0`.
- Publish the same Web UI to the `stable` channel; that run also writes the
  offdesk.dev Web UI pointer for it.
