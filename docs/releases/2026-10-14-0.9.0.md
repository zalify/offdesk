# Desktop, Android and iOS 0.9.0 — a new look

Release scope: desktop macOS, Windows, and Linux (`desktop-v0.9.0`), Android
(`app-v0.9.0`), and iOS through TestFlight (`ios-v0.9.0`).

## Changes

- A new logo and app icon (#522): a desk with a terminal window flying off
  it and a lime `>_` prompt. The desktop, tray, Android launcher and iOS icons,
  the favicons and the DMG background all use it.
- The apps are restyled (#523–#526): a dark terminal look in Geist Mono and
  Geist, with lime as the only accent and coral for waiting and danger.
  - Desktop: tmux-style tabs, pane headers that show who opened a terminal,
    a status line, and restyled palette, menus, file browser and agent
    browser.
  - Phone: a title bar with `[f] [b] [m]`, a strip of terminals waiting on
    you, a waiting card above the keys, and a key bar laid out as an even
    grid, with `↑` above `↓`.
  - First run, sign-in, empty and error screens, and Settings.
- Terminal keys, saved hubs, settings and pairing carry over unchanged.

Desktop and Android apps on 0.8.0 also get the restyle through the stable Web
UI; the new icons need this app version. Nothing changes on the Hub or the
node.

## Validation and publication

- Run CI on the release preparation, then merge and tag `desktop-v0.9.0`,
  `app-v0.9.0`, and `ios-v0.9.0` on the merge commit.
- Verify the desktop draft as for 0.7.8, and that the updated app shows the
  new Dock, taskbar and tray icons. Then publish without moving GitHub's
  global Latest off the Hub release, and check the `desktop-latest` manifest.
- Verify the Android release APK is signed, starts, and shows the new
  launcher icon, and that the iOS build reached TestFlight.
- Publish the same Web UI to the `stable` channel.
