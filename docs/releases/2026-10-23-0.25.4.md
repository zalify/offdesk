# 0.25.4 — Auto mode for started runs, panes that refit on close

Release scope: everything, in the one release `v0.25.4`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.25.3. The new permission mode needs the Hub and node;
the pane fix is interface-only and also reaches 0.25.3 apps through the
`stable` Web UI channel.

## Changes

- **An opt-in `auto` permission mode for started runs** (#595). A run started
  with `permission_mode: "auto"` (`offdesk start --mode auto`, MCP `start_run`,
  or Offdesk's hand-off sheet) goes ahead without asking: Claude starts with
  `--permission-mode auto`, whose classifier still asks before risky actions;
  Codex starts with `--yolo`, with no approvals and no sandbox. It's only used
  when the person starting the run picks it. `--yolo` is on the revive
  allowlist, so a revived Codex run keeps it (OFF-63).
- **Closing a pane refits the panes left** (#593). The remaining panes grew
  into the freed space but kept their old terminal size; they now refit, also
  when a pane closes on another device or its shell exits (OFF-44).

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.4` on the merge
  commit. The Release workflow checks the tag against both versions, builds
  every component into the draft, and publishes it once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded, not skipped.
- After publishing:
  - `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.25.4, and a desktop app on 0.25.3
    offers the update.
  - `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.4.
  - Hand an Offdesk task to Claude with Auto mode on: it starts with
    `--permission-mode auto`. With Codex: it starts with `--yolo`.
  - Split a pane, close one: the pane left fills the width and its terminal
    wraps at the new width.
  - Offer the iOS build to testers with `TestFlight Release Distribution`,
    `release_tag` `v0.25.4`.
- Publish the same Web UI to the `stable` channel.
