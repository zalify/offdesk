# 0.27.1: Offdesk Cloud comments from the terminal

Release scope: everything ships in the one release `v0.27.1`, upgrading from
0.27.0:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux;
- the Android app;
- iOS, through TestFlight.

Only the CLI and the install script changed. The Hub, the node and the apps
are rebuilt at the new version with no other changes.

## Changes

- **`offdesk cloud` (and `odc`): read and post Offdesk Cloud task comments
  from the terminal** (#653, OFF-146).
  - `offdesk cloud login` saves an offdesk.so API key (offdesk.so › Settings ›
    API keys). It asks for the key with echo off, or reads it from stdin.
    `whoami` shows who the key acts for and their teams, and `logout` forgets
    the key.
  - `offdesk cloud comments <task>` lists a task's comments, oldest first, and
    `offdesk cloud comment <task> <text…>` posts one (`-` reads the text from
    stdin; `@username` notifies people). Tasks are given by ref (`OFF-146`, or
    `zalify/OFF-146`) or id.
  - The key is kept apart from the hub's token: the `[cloud]` table of
    config.toml (`url`, `token`), or `OFFDESK_CLOUD_URL` /
    `OFFDESK_CLOUD_TOKEN`. The address defaults to https://offdesk.so. The
    hub's `--url`/`--token` are refused with `cloud`.
  - `odc` is short for `offdesk cloud`. The install script links `odc` to
    `offdesk` beside it, and leaves a different file named `odc` alone.

## Upgrading

- Nothing to do in any particular order: only the CLI changed.
- Run the install script again (`curl -fsSL https://offdesk.dev/install | sh`)
  to get the `odc` link. The desktop app's bundled CLI doesn't add it.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.27.1` on the
  merge commit. The Release workflow checks the tag, builds every component
  into the draft, and publishes the release once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded rather than skipped.
- After publishing:
  - Check that `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.27.1.
  - Install with the script, then `odc login`, `odc whoami` and
    `odc comments <task>` against offdesk.so.
  - Offer the iOS build to testers with `TestFlight Release Distribution`
    (`release_tag` `v0.27.1`).
