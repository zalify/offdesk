# 0.25.1 — Offdesk Cloud on offdesk.so

Release scope: everything, in the one release `v0.25.1`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.25.0.

## Changes

- **Offdesk Cloud is at offdesk.so** (#580). Offdesk Cloud moved from
  `cloud.offdesk.dev` to `https://offdesk.so` on 2026-10-18, and the old
  address now only redirects. Hubs don't follow redirects, so on 0.25.0
  `offdesk-hub cloud check`, sign-in and relay refreshes fail (a running relay
  connection carries on with its saved registration). From 0.25.1 the Hub's
  control API, the desktop app's **Cloud account** button and the docs use
  offdesk.so. Cloud sign-in is Google or email for now; GitHub sign-in returns
  once offdesk.so has its own GitHub OAuth App.
- **Licenses** (#577). The Web UI (`packages/app`) and the desktop, Android and
  iOS apps (`packages/desktop`) are now under FSL-1.1-MIT: anyone can read,
  audit, build, modify and use them, but not offer them as a competing
  product, and each version becomes MIT two years after its release. The Hub,
  node, CLI and the crates under `crates/` stay MIT. This is the first release
  with the split; 0.25.0 and earlier stay entirely MIT. See `LICENSE` and
  `TRADEMARKS.md`.
- **App** (#575, #576, #578, #579). One boot screen from launch to the first
  terminal, with tips; Android's back button and a pairing load go straight to
  the terminal, without a reload or an empty-Hub flash; the browser sign-in
  page says where its link comes from and links the guide; the app's and the
  site's inline mark are the new one.

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.25.1` on the merge
  commit. The Release workflow checks the tag against both versions, builds
  every component into the draft, and publishes it once every asset and
  `latest.json` are in place.
- Check that `updater-channel` and `mirror` uploaded, not skipped.
- After publishing:
  - `https://offdesk.dev/updates/desktop/latest.json` and GitHub's
    `desktop-latest/latest.json` name 0.25.1, and a desktop app on 0.25.0
    offers the update.
  - On a Hub with a managed connection, after updating:
    `offdesk-hub cloud status` shows the relay URL and `offdesk-hub cloud check`
    passes against offdesk.so.
  - `curl -fsSL https://offdesk.dev/install | sh` installs 0.25.1.
  - Offer the iOS build to testers with `TestFlight Release Distribution`,
    `release_tag` `v0.25.1`.
- Publish the same Web UI to the `stable` channel.
