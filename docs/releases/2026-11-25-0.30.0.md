# 0.30.0: Instant terminal switching, pure-Rust pty-daemon canary, and Tailscale direct routes

Release scope: everything ships in the one release `v0.30.0`, upgrading from
0.29.0:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux;
- the Android app;
- iOS, through TestFlight.

The Hub, node, encrypted client, desktop/mobile native shell, and web/bundled
UI all changed.

## Changes

- **Instant terminal switching & multi-agent navigation** (#666).
  - **Mobile LRU keep-alive**: keeps up to 4 recently visited terminals mounted
    in hidden layers so switching back and forth on mobile is 0ms instant with
    no WebSocket/tmux reconnect or scroll reset.
  - **Cold-switch instant snapshot cache**: captures visible viewport lines on
    unmount and renders the last known screen immediately with a subtle
    `syncing…` indicator until live output arrives.
  - **Desktop cross-machine keep-alive**: preserves up to 2 recently active
    machines' workspaces across machine switches.
  - **Power-user Quick Switcher & shortcuts**: direct `Cmd+K` / `Ctrl+Shift+K`
    Command Palette with full-machine `terminals` search (waiting-first, MRU
    ordered, 120ms speculative pre-warm), `Cmd+J` / `Ctrl+Shift+J` last
    terminal toggle, and `Cmd+Shift+A` / `Ctrl+Shift+A` next waiting agent jump.
- **Experimental pure-Rust persistent PTY daemon & mobile HTTPS Hub fix** (#667).
  - **Canary `OFFDESK_PTY_BACKEND=native` backend**: added
    `offdesk-node pty-daemon` running detached (`setsid`) over a Unix domain
    socket with in-memory `vt100` state (10,000-line scrollback), < 1ms attach,
    zero `fork/exec`, zero double-VT transcoding, and full survival across
    `offdesk-node` restarts. Defaults to `tmux` for zero-risk rollout.
  - **Restored Hub web bundle in Docker image**: ensures Android remote-HTTPS
    mode and desktop OAuth login continue working while keeping Web Preview
    removed.
- **Tailscale / CGNAT direct route support** (#668).
  - Recognized `100.64.0.0/10` and `.ts.net` as local/direct addresses in
    `offdesk-protocol` and `offdesk-secure` so Tailscale routes bypass HTTP
    proxies and classify as `RouteKind::Local`.

## Upgrading

- Update the Hub container image, node, CLI, and desktop/mobile apps to 0.30.0.
- To canary-test the pure-Rust PTY daemon on a Unix node, set
  `OFFDESK_PTY_BACKEND=native` in the node service environment (default remains
  `tmux`).

## Validation and publication

- Run CI on the release preparation, then merge and tag `v0.30.0` on the
  merge commit.
