# 0.32.0: Alacritty PTY scrollback engine, mobile Agent Console overhaul & native GPU Stage/Shelf

Release scope: everything ships in the one release `v0.32.0`, upgrading from
0.31.0:

- the Hub, node and CLI;
- the desktop app for macOS, Windows and Linux;
- the Android app;
- iOS, through TestFlight;
- parallel experimental pure-Rust GPU clients (`offdesk-native` for macOS/Linux,
  `offdesk-term-android-jni.zip`, and `OffdeskTerm.xcframework.zip`).

## Changes

- **Native PTY daemon (`offdesk-node`) scrollback & CJK fix**:
  - Replaced `vt100` with `alacritty_terminal 0.25` in `pty-daemon`, fixing
    missing scrollback whenever `DECSTBM` scroll regions are active (e.g.
    full-screen agent TUIs) and ensuring crisp CJK wide-character alignment.
  - Added explicit DECSTBM reset + synchronized viewport repaint on attach and
    resize, plus a desktop `0 -> 1` initial fit retry in `TerminalCanvas` so
    newly created terminals fit the viewport cleanly.
- **Mobile Agent Console UI overhaul**:
  - Added a native auto-growing Compose Bar with full Chinese IME & voice
    dictation support and a collapsible extended keybar persisted across
    sessions.
  - Replaced legacy `[f]/[b]/[m]` header chrome with compact icon controls, a
    one-tap `● waiting` jump pill, and `All / Waiting / Working` status filters
    in the Sessions Sheet.
- **Shared native Rust GPU engine (`crates/native-term`) & multi-platform clients**:
  - Extracted `liboffdesk_term` (`wgpu + glyphon + alacritty_terminal`) with
    C-ABI, Android JNI (`NativeConsoleScreen.kt`), and iOS Metal
    (`NativeConsoleView.swift`) shells.
  - Added **Project Grouping** (zero-config, collapsing git worktrees under
    their repo), **Foreground Stage Layouts** (`Focus [▢]`, `Split [◫]`,
    `Master+Stack [◧]`, `Grid 2×2 [⊞]` with one-click `[▶]` focus-project and
    `[↖]` swap-to-master), and an auto-hidden **Background Shelf** (`[—]`
    minimize without killing, `waiting` pills sorted first).
