# v0.33.4

## What changed

- **Interactive CLI TUI & raw-TTY attach (`offdesk tui`, `offdesk attach`)** (#722): fuzzy-search and attach directly to any remote terminal across all machines right inside Ghostty, Alacritty, iTerm2, or Kitty with native GPU rendering, native macOS IME, live resize, and `Ctrl+]` instant detach/switch.
- **Cross-device synced manual terminal rename** (#719): hub-persisted `custom_title` (`PATCH /api/machines/{id}/terminals/{tid}`) synced live across desktop, phone, and foldable without being overwritten by OSC title updates. Right-click `rename` or double-click in desktop sidebar; long-press `Rename terminal` on mobile.
- **Ghostty-style smooth resize HUD & transitions** (#719): frosted-glass centered `cols × rows` HUD pill, faster 75ms resize debounce, and smooth opacity/sidebar transitions.
- **Native Rust terminal P0/P1 parity** (#709, #710, #715, #716, #718):
  - Live CJK/Pinyin IME preedit rendering at cursor, WKWebView post-composition `Enter` guard, and blur reset.
  - Full 10,000-line scrollback `⌘F` search with bright active-match highlight and fixed jump when `wants_mouse` is active.
  - Soft-wrap copy (`CellFlags::WRAPLINE`), TUI mouse click forwarding (`Shift`/`Option` forces local selection), crisp block-cursor character contrast, ANSI `HIDDEN`, reconnect input queue, wake-from-sleep reconnect, and cross-monitor DPI refresh.
  - `pty-daemon` mouse-mode replay on attach/reconnect so Claude Code scroll never stalls after reconnect.
- **Mobile & foldable UX** (#706, #707, #708, #717):
  - Mobile Tauri defaults back to `xterm.js` for full touch scroll & mobile IME parity while desktop stays on Native Rust.
  - Collapsible 216px left session navigation sidebar + right-docked split Drafts & Files drawers on unfolded foldables (`>= 680px`).
  - Removed duplicate `Message agent…` compose box and added a slim `take control` strip while watching.
