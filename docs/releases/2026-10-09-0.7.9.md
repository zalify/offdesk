# Desktop, Android and iOS 0.7.9 — File preview

Release scope: desktop macOS, Windows, and Linux (`desktop-v0.7.9`), Android
(`app-v0.7.9`), and iOS through TestFlight (`ios-v0.7.9`).

## Changes

- Preview files in the file browser instead of downloading them first.
  Word (`.docx`), Markdown, PDF, text and code, and images open in place;
  下载 is in the preview header. PDFs render through pdf.js, so they work
  in every shell, including CJK and scanned (JPEG2000) PDFs. Document HTML
  renders in a sandboxed frame with no scripts or remote loads.

## Validation and publication

- Run CI on the release preparation, then merge and tag `desktop-v0.7.9`,
  `app-v0.7.9`, and `ios-v0.7.9` on the merge commit.
- Verify the desktop draft as for 0.7.8, then publish without moving
  GitHub's global Latest off the Hub release, and check the `desktop-latest`
  manifest.
- Verify the Android release APK is signed and starts, and that the iOS
  build reached TestFlight.
- Publish the same Web UI to the `stable` channel.
