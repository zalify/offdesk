# Desktop, Android and iOS 0.7.11 — HTML file previews

Release scope: desktop macOS, Windows, and Linux (`desktop-v0.7.11`), Android
(`app-v0.7.11`), and iOS through TestFlight (`ios-v0.7.11`).

## Changes

- The file browser shows an `.html` file of a machine as a web page: open
  the file, then **Preview**. The page gets a WebView of its own (a window on
  the desktop, a full-screen view on Android with ✕, ↻ and Back), and every
  file it asks for is read from the machine through the app's connection. It
  can read only the git checkout around the file, never hidden files. See
  [HTML file previews](../html-file-previews.md). Not on iOS yet.
- Paths and commands Claude Code wraps across rows open and copy as one line
  (#513, #514). Desktop and Android already have these through the stable Web
  UI; this brings them to iOS.

Previews need this app version: an older app with the newer Web UI says to
update. Nothing changes on the Hub or the node.

## Validation and publication

- Run CI on the release preparation, then merge and tag `desktop-v0.7.11`,
  `app-v0.7.11`, and `ios-v0.7.11` on the merge commit.
- Verify the desktop draft as for 0.7.8, then publish without moving
  GitHub's global Latest off the Hub release, and check the `desktop-latest`
  manifest.
- Verify the Android release APK is signed and starts, and that the iOS
  build reached TestFlight.
- Publish the same Web UI to the `stable` channel.
