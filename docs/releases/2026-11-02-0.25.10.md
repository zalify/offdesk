# 0.25.10 — Agent runs stay on their task with Claude Code's native build

Release scope: everything, in the one release `v0.25.10`: the Hub, node and CLI,
the desktop app for macOS, Windows and Linux, the Android app, and iOS through
TestFlight, all from 0.25.9. The fix is in the Hub and the node, so it needs
this release. The interface doesn't change.

## Changes

- **Agent runs keep their task when Claude Code's native build runs** (#611,
  OFF-107). tmux shows the native build as its version (`2.1.307`), which the
  node didn't know. It reported no agent, and if that report came after
  Claude's `SessionStart` hook, the Hub ended the run a few seconds in. A task
  handed to an agent then came back Stopped while the agent worked on in a new
  run with no task, whose reports reached nobody.
  - The node recognises the native build, for agent runs and for confirmations
    on screen, and no longer says "no agent" about a terminal it never saw one
    in.
  - A run that ends without a report passes its task to a run opened in the
    same terminal within 60 seconds.
  - After `offdesk run done`, the rest of that turn opens no blank run. The next
    prompt opens one with the name but not the task, which stays with its
    person for review.

## Upgrading

- The Hub and the node both need the update. A new Hub with an old node still
  ends these runs, but the next run takes the task over, so the task shows a
  Stopped comment and goes on.
- When the updated node first reports Claude in terminals that have no open
  run, each gets a `working` run until its next hook. They carry no task.
- If a Hub dies and an agent exits while it's down, the old run stays open until
  its terminal closes. A clean node disconnect ends runs as before.
