# Desktop and Android 0.7.8 — Web UI updates

Release scope: desktop macOS, Windows, and Linux (`desktop-v0.7.8`) and
Android (`app-v0.7.8`). iOS is not part of this release.

## Changes

- The macOS and Android apps take interface updates without reinstalling.
  They download signed Web UI bundles from the `ui-stable` channel, verify
  them against a key built into the app, stage them in the background, and
  switch on the next cold start. A bundle that does not start correctly rolls
  back to the previous interface. Windows and Linux keep the interface they
  ship with.
- Upload local files into the agent browser's file inputs.
- Android catches up with everything since 0.7.4. This includes the agent
  browser, file browsing and downloads, pane layout tools, the tab strip
  without scrollbars, and the removal of the agent relay and to-dos.

## Validation and publication

- Run CI on the release preparation, then merge and tag `desktop-v0.7.8` and
  `app-v0.7.8` on the merge commit.
- Verify the desktop draft as for 0.7.7: macOS signing and notarization, the
  DMG, and the updater manifest. Then publish without moving GitHub's global
  Latest off the Hub release, and check the `desktop-latest` manifest.
- Verify the Android release: the APK is signed with the release key and
  starts.
- Publish the same Web UI to the `stable` channel so 0.7.8 installs have a
  signed bundle to follow.
