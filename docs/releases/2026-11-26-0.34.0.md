# v0.34.0

A Hub, node and CLI release. The agent browser gets private tabs and tabs that belong to their terminal; drafts get databases, version history, share links and tags; the terminal and the phone layout get a round of fixes.

## What changed

### Agent browser

- **Private tabs** (#721): `offdesk browser open --private [URL]` (MCP: `browser_open` with `private: true`) opens the tab in a fresh, isolated browser context. It has none of the machine's cookies or logins, shares nothing with any other private tab, and is gone when its last tab closes. Pages it opens stay in the same context. The tab is marked `[private]` in `offdesk browser ls` and in the app.
- **Tabs close with their terminal** (#721): when a terminal is closed or its command exits, the Hub closes the agent browsers that terminal opened, also while a person is controlling one. Tabs with no opener (opened from the app's **+**, or from a CLI on another machine) stay until closed by hand.
- **Tabs show their owner** (#721): the desktop tab strip, the mini window and the phone tab strip label each tab with the name of the terminal that opened it. The "needs you" and "took control back" toasts name that terminal. Opening the browser lands on a tab that is asking for a person, then on the focused terminal's tab, then on the last one viewed.
- **Mini window** (#699): the desktop browser overlay minimises to a small live window in the corner that keeps control and can hand it back.

### Drafts

- **Draft databases** (#711): Notion-style tables for agents, with a Hub API, the `offdesk db` CLI, and table and board views.
- **Version history and public share links** for drafts and databases (#712).
- **Multi-level tags** (#714): a tag tree, a card stream, and `offdesk draft --tag`.
- The preview no longer snaps its horizontal scroll back (#720).

### Terminal

- **Manual terminal rename, synced across devices**, and a smoother resize HUD (#719).
- Native terminal fixes (#716): IME reset on blur, mouse clicks in TUIs, copying soft-wrapped lines, Cmd+F over the full history with highlight, cursor contrast, the reconnect queue, DPI.
- Cmd+F jump and highlight are no longer cancelled by the snap to bottom (#718).
- Mouse mode is replayed on attach, and the wheel is forwarded to the remote program when the local scrollback is empty or holds only a few stray lines (#709, #710).
- IME: the preedit text is drawn at the cursor, and the trailing Enter WKWebView sends after a composition ends is swallowed (#715).

### CLI

- **`offdesk tui`**, an interactive session picker, and **`offdesk attach`**, a raw-TTY attach to a terminal (#722).

### Phone and tablet

- Unfolded foldables get a collapsible session sidebar on the left and split drawers on the right (#717).
- The duplicate "Message agent" box is gone; a slim take-control strip shows while watching (#708).
- The canvas no longer squashes when the keyboard resizes it; touch scrolling and a Take Control button (#706).
- The mobile app defaults to the xterm.js renderer; the desktop stays on the native one (#707).

## Updating

- **Private tabs need all three at this version or later**: the Hub, the node (`offdesk-node`, on the machine that runs the browser) and the CLI (`offdesk`, where the agent runs). The Hub parses each browser command before forwarding it, so an older Hub drops the `private` field, and an older node ignores it. The CLI and the MCP tool check the reply: if the tab is not private, they close it and fail instead of leaving a tab that shares the machine's logins. Update the Hub first.
- Closing tabs with their terminal needs only the Hub.
- Owner labels and the mini window need only the app (the Web UI bundle).
- `offdesk db` and `offdesk draft --tag` need the Hub and the CLI.

## Known limits

- After a node reconnects, a browser whose terminal ended while the node was away can stay open if the node reports its terminals before its browsers. Close it by hand.

## Check after publishing

- `offdesk browser open --help` lists `--private`.
- `offdesk browser open --private https://example.com` prints an id, and `offdesk browser ls` marks that tab `[private]`. A site you are logged in to in a normal tab shows you logged out in the private one.
- Open a browser from a terminal, then close the terminal: the tab is gone from `offdesk browser ls` within a few seconds.
- In the app, the tab strip shows the terminal's name next to the page title.
